개인정보처리방침

사동고 교무수첩 · 시행일 2026년 10월 26일

1. 수집하는 정보

교무수첩은 사용자가 구글 달력 연동을 직접 선택한 경우에만 다음 정보를 사용합니다.

  • 구글 계정의 이름과 이메일 주소 (연결된 계정을 화면에 표시하기 위해)
  • 사용자가 고른 구글 달력의 일정 (제목, 날짜·시각)

2. 이용 목적

교무수첩 달력과 구글 달력의 일정을 서로 맞추는 데에만 사용합니다. 교무수첩에서 쓴 일정을 구글 달력에 넣고, 구글 달력의 일정을 교무수첩에 보여주며, 한쪽에서 고치거나 지운 일정을 다른 쪽에도 반영합니다. 광고, 분석, 그 밖의 목적으로는 사용하지 않습니다.

3. 저장 위치

  • 모든 정보는 사용자 본인의 PC에만 저장됩니다. 제작자나 별도 서버로 전송하지 않습니다.
  • 구글 연결 정보(접근 열쇠)는 Windows 암호화 기능으로 암호화하여 PC에 저장합니다. 사용자의 구글 비밀번호는 교무수첩이 받거나 저장하지 않습니다.

4. 제3자 제공

수집한 정보를 누구에게도 제공하거나 판매하지 않습니다. 일정 정보는 사용자의 PC와 구글(Google LLC) 사이에서만 오갑니다.

5. 연결 해제와 삭제

  • 교무수첩의 🔗 연동 → 연결 해제를 누르면 접근 권한이 취소되고, PC에 저장된 연결 정보가 지워집니다.
  • 구글 계정의 타사 앱 및 서비스 화면에서도 언제든 권한을 취소할 수 있습니다.
  • 교무수첩을 제거하고 사용자 폴더(%APPDATA%\사동고 교무수첩)를 지우면 PC에 남은 모든 정보가 삭제됩니다.

6. 구글 API 서비스 사용자 데이터 정책 준수

교무수첩이 구글 API로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
